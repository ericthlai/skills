# Routing cases

`routing-cases.json` records the intended boundary between the three skills and ordinary agent work.
It includes positive, negative, and overlap cases so description changes can be reviewed against
concrete prompts.

This is an unscored corpus. It has not been run as a model benchmark, and the repository makes no
routing-accuracy claim. A future evaluation should record the host, model, date, observed selection,
and whether the expected skill was loaded before publishing any result.
